# 🏋️ Gym Management System

A Gym Management System built with **ASP.NET Core MVC** to simplify gym operations by managing members, trainers, memberships, training sessions, and bookings through a clean and scalable architecture.

---

## 🚀 Features

### 📊 Dashboard
- View gym statistics and reports.

### 👤 Member Management
- Add, update, delete, and search members.
- Store member profiles and health records.

### 🏋️ Trainer Management
- Manage trainers and their information.
- Assign trainers to training sessions.

### 💳 Membership Management
- Create and manage membership plans.
- Track active memberships.

### 📅 Session Management
- Create training sessions.
- Assign trainers and categories.
- Manage attendance and session capacity.

### 🔐 Authentication & Authorization
- Secure login system.
- Role-based authorization using ASP.NET Core Identity.

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/a7medmohamed116/MyGym.git
```

2. Open the solution.

3. Update the connection string in

```text
appsettings.json
```

4. Apply migrations

```powershell
Update-Database
```

5. Run the project.
